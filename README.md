# PDD Local Publisher

一个不使用 AI、完全在浏览器本地运行的拼多多商家后台上货辅助扩展。

> 当前版本是可运行的 MVP。拼多多会按类目动态生成属性与 SKU 表单，而且后台页面可能随时改版。首次用于真实店铺前，请用测试商品逐字段校准；默认设置只填写页面，不自动提交。

## 功能

- 导入 CSV 或 JSON 商品数据并建立本地任务队列
- 自动匹配并填写标题、描述、价格、库存、物流模板和发货时效
- 直接从电脑选择主图和详情图，图片保存在扩展本地数据库
- 也可从 URL 下载主图、详情图并交给页面上传控件
- 按名称填写商品属性
- 根据 SKU 中的 `spec` 创建“款式”“型号”等规格及规格值
- 对生成后的 SKU 组合表格填写价格、市场价和库存
- 保存草稿或在二次确认后提交发布
- 记录最近 500 条执行日志，可导出 JSON
- 自定义字段文字映射，适配后台文案变化

所有商品数据、设置和日志都存放在 `chrome.storage.local`。扩展没有自己的服务器。

## 安装

1. 下载或克隆本仓库。
2. Chrome/Edge 打开扩展管理页。
3. 开启“开发者模式”。
4. 选择“加载已解压的扩展程序”，选择本仓库目录。
5. 登录拼多多商家后台。

## 使用

1. 点击扩展图标，下载 CSV 模板或参考 `examples/products.example.json`。
2. 多规格直接分行填写“款式、型号、规格价格、规格库存”。同一商品的“商品编号”保持一致，导入时会自动合并为一个商品。
3. 导入商品表，在扩展顶部选择商品，点击“选择主图”或“选择详情图”，直接从电脑多选图片；也可以在任务卡片单独补图。
4. JSON 导入仍支持在 SKU 的 `spec` 中提供多个规格，例如 `{"款式":"标准款","型号":"500型"}`。
5. 点击“打开下一个商品”，等发布页面加载完成后，使用右下角面板的“填写页面”。
6. 人工检查类目、属性、SKU 和图片，之后保存草稿或提交。

## 数据字段

| 字段 | 含义 |
| --- | --- |
| `title` | 商品标题，必填 |
| `category_path` | 类目路径，用 `>` 分隔 |
| `carousel_images` | 主图 URL 数组；CSV 中用 `|` 分隔 |
| `detail_images` | 详情图 URL 数组；CSV 中用 `|` 分隔 |
| `商品编号` | 同一商品的多行使用相同编号，扩展会合并多规格 |
| `款式` / `型号` | 可直接查看和编辑的销售规格 |
| `规格价格` / `规格市场价` / `规格库存` | 当前款式与型号组合对应的数值 |
| `video_url` | 视频地址，当前保留字段 |
| `price` / `market_price` | 默认价格/市场价 |
| `stock` | 默认库存 |
| `attributes` | JSON 对象，键为页面属性名称 |
| `skus` | JSON 数组，每项可含 `spec`、`price`、`market_price`、`stock` |
| `logistics_template` | 物流模板显示名称 |
| `shipping_hours` | 发货小时数 |
| `description` | 商品描述 |

CSV 同时接受中文表头，例如“商品标题”“主图”“详情图”“拼单价”“库存”。

## 安全设计

- 默认不自动保存或提交。
- 自动提交前仍弹出浏览器确认框。
- 不读取或保存账号密码。
- 图片由扩展后台直接下载，下载请求不携带拼多多登录凭证。
- 开放 HTTP/HTTPS 主机权限仅用于下载用户导入的图片 URL。

## 已知限制

- 类目级联选择、销售属性组合创建高度依赖具体类目，通用版本只能匹配已出现的控件。
- 页面使用自定义下拉框时，可能需要在设置中添加字段映射或为具体类目增加适配器。
- 图片站点如果阻止外部下载，扩展无法上传对应图片。
- 本地图片保存在扩展的 IndexedDB；清除浏览器扩展数据或卸载扩展会删除这些图片。
- 发布结果最终以拼多多页面反馈和平台审核为准。

## 开发检查

项目不需要打包或安装依赖。修改后可以执行：

```powershell
node --check popup/popup.js
node --check content/content-script.js
node --check background/service-worker.js
```
